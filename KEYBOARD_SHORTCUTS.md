# ⌨️ Keyboard Shortcuts & Controls - Designing Page

## Mouse Controls

| Action | How To | Result |
|--------|--------|--------|
| **Zoom In/Out** | Scroll mouse wheel | Zooms centered on cursor |
| **Pan Canvas** | Hold `Space` + Drag | Move around without affecting zoom |
| **Pan Canvas (Alt)** | Middle mouse + Drag | Alternative pan method |
| **Select Object** | Click object | Shows transform controls |
| **Multi-Select** | Click + drag area | Select multiple objects |
| **Move Object** | Drag object | Reposition on canvas |
| **Resize Object** | Drag corner handles | Scale object |
| **Rotate Object** | Drag rotation handle | Rotate around center |

## Keyboard Shortcuts

### Navigation
| Key | Action |
|-----|--------|
| `Space + Drag` | Pan around canvas |
| `Mouse Wheel` | Zoom in/out (at cursor) |

### Editing
| Key | Action |
|-----|--------|
| `Ctrl + A` | Select all objects |
| `Delete` or `Backspace` | Delete selected object(s) |
| `Ctrl + Z` | Undo last action |
| `Ctrl + Shift + Z` or `Ctrl + Y` | Redo |
| `Ctrl + G` | Group selected objects |
| `Ctrl + Shift + G` | Ungroup selected group |

### Text Editing (when text selected)
| Key | Action |
|-----|--------|
| Double-click text | Enter edit mode |
| `Esc` | Exit edit mode |
| Standard text shortcuts | Copy/Paste/Cut work as expected |

## Pro Tips 💡

### Image Upload
```
Drag & drop anywhere in upload panel
or
Click "Pick from device"

Supports: PNG, JPEG, GIF, WebP
Max recommended: 10MB
```

### Zoom Navigation
```
For precision work:
1. Wheel zoom to 200-300%
2. Space + drag to position
3. Edit details
4. Click ⊡ to reset view
```

### Multi-View Workflow
```
Design front first:
1. Add all front elements
2. Click "Back side"
3. Design back elements
4. Toggle back and forth to compare
5. Green dots show which views have content
```

### Selection Tips
```
Single click → Select one object
Click + drag area → Multi-select
Ctrl + A → Select all
Shift + click → Add to selection
```

### Object Manipulation
```
Drag → Move
Corner handles → Resize
Top handle → Rotate
Alt + drag → Duplicate (coming soon)
```

## Common Workflows

### Upload & Position Logo
```
1. Click "Upload" in left sidebar
2. Drop your logo file
3. Logo appears centered
4. Drag to reposition
5. Resize from corners if needed
```

### Add Styled Text
```
1. Click "Add text" in left sidebar
2. Choose a pre-designed template OR
3. Select a font
4. Text appears on canvas
5. Double-click to edit text
6. Use toolbar to adjust style
```

### Design Both Sides
```
1. Design front completely
2. Click "Back side" button
3. Add back design elements
4. Click "Front side" to verify
5. Notice green dots on buttons
```

### Zoom for Detail Work
```
1. Hover over area you want to zoom
2. Scroll mouse wheel up
3. Make precise adjustments
4. Scroll down or click ⊡ to zoom out
```

## Troubleshooting

### "Space + drag doesn't work"
→ Make sure canvas is focused (click it first)
→ Try middle mouse button instead

### "Zoom is too sensitive"
→ Use +/- buttons for controlled zoom
→ Wheel zoom is cursor-based (more precise)

### "Lost my design when switching views"
→ Designs auto-save per view
→ Click back to original view to restore
→ Green dots indicate which views have content

### "Can't select object after zooming"
→ Objects remain selectable at all zooms
→ Try clicking directly on the object (not empty space)
