FIX AUTHENTICATION AND ACCESS CONTROL BUGS
============================================

CURRENT SECURITY ISSUES
=======================

Bug 1: Logged-in users can access Login page
File: src/app/app.routes.ts (line 26)
- Problem: { path: 'login', component: LoginComponent } has no guard
- Impact: Authenticated users (both admin and customer) can still visit /login
- Expected: Should redirect based on role (admin -> /admin/dashboard, customer -> /apparel)

Bug 2: Logged-in users can access Signup page
File: src/app/app.routes.ts (line 27)
- Problem: { path: 'signup', component: SignupComponent } has no guard
- Impact: Authenticated users can still visit /signup
- Expected: Should redirect based on role

Bug 3: Missing GuestGuard
Location: src/app/guards/ directory
- Problem: No guard exists to prevent authenticated users from accessing guest-only pages
- Impact: Login/Signup pages are accessible to logged-in users

Admin Routes Already Protected
File: src/app/guards/admin.guard.ts (lines 16-19)
- Status: Working correctly
- Protection: Customers trying to access /admin/* routes are redirected to /apparel
- No fix needed

SOLUTION
========

1. Create GuestGuard
File: src/app/guards/guest.guard.ts (new file)

The guard should:
- Check if user is authenticated
- If authenticated and role is 'employee' -> redirect to /admin/dashboard
- If authenticated and role is 'customer' -> redirect to /apparel
- If not authenticated -> allow access to login/signup

2. Update Routes Configuration
File: src/app/app.routes.ts

Apply GuestGuard to:
- Login route (line 26)
- Signup route (line 27)
